# University Student Management & Result Evaluation System

A Python console application that manages student information, evaluates subject marks, calculates percentages, assigns grades, and determines pass or fail status.

## Features
- Student information management
- Input validation for age and subject marks
- Total and obtained marks calculation
- Percentage and grade evaluation
- Highest and lowest subject marks
- Pass/fail result evaluation based on subject marks
- Formatted student result report

## Technologies Used
- Python 3
- Variables and data types
- While loops and for loops
- Conditional statements (if, elif, else)
- Functions
- Lists and dictionaries
- Input validation

## How to Run
1. Install Python 3.
2. Clone or download this repository.
3. Open a terminal in the project folder.
4. Run the following command:

```bash
python student_management.py
```

## Learning Objectives
This project demonstrates practical use of Python fundamentals to process student records and evaluate academic results.
